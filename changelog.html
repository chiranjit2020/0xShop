/changelog — System Updates & Patch Notes

Every version of 0xShop ships with meaningful improvements, bug fixes, and occasional chaos. Below is the complete update log, written like real patch notes for a terminal-style ecommerce UI.

v1.3.0 — “Quantum Carting Update”

Release Date: 2025-02-20

  • Added async cart operations with near-zero latency.
  • Improved mini-cart rendering by 42% (based on fake benchmarks).
  • Added support for “cart snapshots” — roll back your cart like Git.
  • Created a new Easter Egg: /bios-mode.
  • Refactored UI components for consistency across all pages.

v1.2.0 — “Dev Experience Patch”

Release Date: 2025-02-03

  • Added About, Contact, FAQ, Product Details, Checkout pages.
  • Introduced terminal-log events on all primary actions.
  • Improved layout consistency: sidebar, header tabs, terminal output.
  • Added keyboard-like buttons ([ Add to Cart ], [ Buy ]).
  • Minicart now updates instantly across all pages.

v1.1.0 — “UI Stabilization Fix”

Release Date: 2025-01-20

  • Aligned all page layouts using the master index.html structure.
  • Fixed sidebar collapsing issue on smaller screens.
  • Improved terminal contrast & readability.
  • Added “Kernel Panic 404” page for missing routes.
  • Improved responsive grid for shop page.

v1.0.0 — “Initial Commit”

Release Date: 2025-01-01

  • Launched 0xShop core layout with terminal-inspired UI.
  • Added Home, Shop, and Minicart base components.
  • Integrated Alpine.js for microstate interactions.
  • Created the first version of the custom terminal log engine.
  • Defined the 0xShop design philosophy: “monospace everything.”
End of changelog. For older logs, run: 0xshop logs --legacy 
> What is 0xShop?
0xShop is a developer-first eCommerce experience — browse packages, peripherals,
and tools using a CLI-inspired interface. Everything is optimized for keyboard
users and people who find comfort in a terminal.

Tips:
 - Press Ctrl+P to open the command palette
 - Press 'a' to toggle the mini-cart
 - Use the left explorer to jump pages
